# U3: World, characters and gestures

Package spec for the Civilisation and Divinity run (owner brief 26 Nov 2026 §40). Self-contained. Paths start at the repository root. "Contracts" = [SHARED_ARCHITECTURAL_CONTRACTS.md](../SHARED_ARCHITECTURAL_CONTRACTS.md) (binding). U3 **absorbs the brief's U4** (character look and animation; index §0): every design reference to "U4" means this package. This is a **view package**: it animates events and never decides anything.

## 1. Identifier

**U3**, two parts:
- **U3a** (Tier 1, Checkpoint A or B, whichever Unity run it makes; about 1.5 h). **Status: in progress** since 27 Nov 2026, by a Sonnet agent on branch **`unity/u3a`** in worktree **`wt-lrs-u3a`**, cut from `unity/poc` at `c1ab594`. This spec describes the scope that agent is working to; it does not restart it.
- **U3b** (Tier 2, Checkpoint D, about 5 h). Not started. Branch **`unity/u3b`**, worktree `wt-lrs-u3b` (or the warm `wt-lrs-u3a` folder on a new branch after U3a has merged).

## 2. Objective

The island looks seamless with the Catan grid hidden in normal play (D5.18-D5.20); NPCs communicate non-verbally (D5.24) and decoded text appears only in an optional developer/accessibility overlay, off by default (D5.25; acceptance **M5.18**); characters show their state (D5.21); gestures use a reusable body-animation vocabulary that follows real events (**M5.19**); divine effects animate only real sim events (brief §29).

## 3. User-facing outcome

U3a: in normal play no hex outlines, no producing-hex glow and no text above anyone's head; the island is one landscape. A developer (or accessibility user) can switch on a decode overlay that shows what each speaker intended and what each listener understood. U3b: villagers request, offer, give, receive, accept, refuse, warn, cooperate and beg with recognisable body language; goods pass visibly hand to hand at the tick they move; injured people limp with bandages, the sick are pale and slumped, the tired droop, pregnant women show; and the divine acts are readable at a glance: a pale halo for a suggestion, a gold beam for a command, a violet yoke for compulsion, a rim in the god's colour for possession, a column of light for the avatar, a spiral for healing, a bolt for a smite, motes condensing into a real lot for creation.

**U3b (Tier 2):**
- **M5.19 vocabulary:** a pure `GestureAnimationPlanner` (no Unity types; in `Assets/God/Game/Animation/`) mapping events to `AnimationCue { Id, SourceEventId, Actor, Kind, Target, Object, StartTick, Phases, Intensity }`; per-actor cue queues; `PoseSequencer` and a `PoseLayer` blending over walk/work on the existing rig. The avatar gets its own distinct model (never the NPC figure).
- If time remains (Tier 2, lower priority): settlement clusters and curved paths (VISUAL_WORLD §7-8).
- Leave room for the **industrial workstream** (I6: industrial buildings, moving harvesters with visible cargo, vehicle and deposit visuals; owner D6.19): the planner's event-to-cue table and the effect planner are data tables keyed by event code, so later packages register cue kinds for vehicles and machines without changing U3's code.
