# D3: Miracles

Package spec for the Civilisation and Divinity run (owner brief 26 Nov 2026 §40). Self-contained. Paths are relative to `Assets/God/Sim/` unless they start with `Assets/`, `DotNet/` or `docs/`. "Contracts" = [SHARED_ARCHITECTURAL_CONTRACTS.md](../SHARED_ARCHITECTURAL_CONTRACTS.md) (binding).

## 1. Identifier

**D3**, Tier 1, Checkpoint **B**. Effort about 2.5 agent-hours. Branch `unity/d3`, worktree `wt-lrs-d3`.

## 2. Objective

Validated deterministic miracles that **genuinely change authoritative state** (D5.11; brief §10): heal injury, heal disease, smite a person, smite a hut, smite a resource source, create and destroy basic resources with an exact miracle ledger (conservation C1 unchanged, new C7 and C8), bless and protect as minimal timed modifiers, and (Tier 2, last) consecrate a place. Scenario 12: heal or smite with genuine state changes and observable consequences.

## 3. User-facing outcome

The player heals an injured person and the injury value in the card really falls; smites a thief, who is hurt (or killed, opening an estate as any death) and witnesses become afraid; creates five berries on the ground that a hungry person then picks up; destroys goods; burns a hut whose stored food scatters on the ground; withers a tree. Every created or destroyed unit appears in the ledger. Nothing is a visual effect without a state change.

## 6. Allowed scope

- `CastMiracle { God, Kind, Target, Magnitude }` handler with common rules: preconditions from true state; `Validate` never mutates; `Apply` refuses before spending if the effect would change nothing (I-MY-6), then `Mythic.TrySpend`, `Interventions.Open`, effect, `MiracleCast` (825) and one `MiracleEffectApplied` (826) per affected thing with before/after (I-MY-3); every resulting ordinary event (`InjuryTaken`, `IllnessEnded`, `Produced`, `Consumed`, `ItemMoved`, `NpcDied`, `BuildingDestroyed`) carries the `InterventionId`.
- Kinds, Tier 1: `HealInjury 1` (`Bodies.Heal(..., Injury, magnitude)`; pain share; infection risk ends below 300), `HealDisease 2` (through the M4 heal hook: `Recovered`, immunity 15 days, severity 0, health +100), `SmitePerson 5` (`Bodies.Damage(..., DamageCause.Divine, actor 0, intervention)`; fear +400; protection applied first; cap `SmiteMax` 800; death through `PopulationModule.Kill(DeathCause.Violence)` with the attribution in `MiracleEffectApplied`; **no new `DeathCause`**: `DeathsByCause` is a hashed `int[9]`, contracts 20.4), `SmiteBuilding 6` (huts: empty bins by `Goods.Move` to the ground at the bin's node, `MoveReason.Drop`, or `Consume(Miracle)` with `SmiteBurnsContents`; sleeping rights end; territory buildings: the existing destruction path), `SmiteSource 7` (stock falls; `SmiteBlights` suspends regrowth `BlightDays`), `CreateResource 8` (`Goods.Produce(..., ProduceReason.Miracle, actor 0, source = intervention)` into ground, a person's carry with owner `Npc(target)` basis `Miracle`, or a bin; count 1-10; basic personal wares only; never where nobody can reach), `DestroyResource 9` (`Goods.Consume(..., ConsumeReason.Miracle, actor 0, refId = intervention)`; never an open estate bin), `Bless 3` and `Protect 4` minimal (`Blessing { Npc, Kind, Until, God, Intervention }`, at most one of each per person; protect multiplies damage by `ProtectPermille` 300 in `Bodies.Damage`; bless adds daily recovery and halves hazard/infection chances through the M4 health-roll hook).
- `DivineLedger.Book(...)` (the only allocator of `LedgerId`): exactly one `ResourceCreated` (827) or `ResourceDestroyed` (828) per miracle `Produce`/`Consume`, booked per god per ware in `DivinityState.Miracles.Ledger`; invariant **C7** checked in `DivinityModule.Check` at day boundaries (via D3's partial or a D3-provided check function D1 calls).
- `Bodies.Heal`/`Damage` hook bodies for persons (`DivinityHooks.D3.cs`).
- Population-module additions: a **hut-removal function** and a **source-stock function** (smite, blight). `PopulationModule` is a non-partial static class today, so either (a) F1 has made it `static partial` and D3 adds `Population/PopulationModule.Miracles.cs`, or (b) D3 adds a new static class `Population/PopulationMiracles.cs` that uses only public API, or (c) an additive edit to `PopulationModule.cs` **flagged in the hand-back for the lead's review**. Prefer (b); do not change existing behaviour.
- Witnesses: a `DivineSign` ring entry at the target node (64 entries, DIVINE_PLAYER §4.8); attending people within sight of a smite get `SituationKind.SmiteWitnessed` (83) through the sense seam and fear through the normal channel; the victim gets `SelfFeature.Smitten` (48), a healed person `SelfFeature.Healed` (49), a blessed one `Blessed` (50) for `Miracles.MemoryDays`. **The sim never tells the victim why** (brief §14): learning credit goes to whatever its recent traces were.
- Tier 2, last: `Consecrate 12` (`ConsecratedPlace { Id = intervention, God, Node, Radius, SinceTick }` in `DivinityState.Miracles`, spacing `SacredSpacing` 6 nodes, perceived through `SenseExtra` as `ObjClass.Shrine` 80 and `SituationKind.ConsecratedPlace` 82; `LocationConsecrated` 829). If time remains after Consecrate: `RevealKnowledge 10` (`BeliefStore.Upsert` into the target's own mind with the true node; never into a record) — see "Inconsistencies" in the hand-back report if you do it, since the index does not list it.
- **Hook for K1 (industrial knowledge and designs, designed concurrently in [KNOWLEDGE_AND_TECHNOLOGY_DESIGN.md §10.4](../../stage4/KNOWLEDGE_AND_TECHNOLOGY_DESIGN.md), draft):** keep `RevealTechnology 11` refused with `act_unavailable`, but route it through one seam in `Miracles.cs`: a static delegate or partial method `Miracles.RevealTechnology` (validate + apply, given the god, target person, a design id carried in `Magnitude` or `Target.Id`, and the intervention id) that is **null/empty in D3, so the kind is refused**. K1 will supply the body (the person gains `KnownDesign(..., Source = Revealed(intervention))`; D3's `MiracleCast`/`MiracleEffectApplied` are still emitted by D3's common path; cost from D3's tuning table). Revelation confers knowledge only, **never ownership, a patent or an asset** (owner D6.10). Do not create any design or knowledge state.

## 7. Excluded scope

- `RevealTechnology` behaviour (refused; K1/C7 later), area miracles (`Area 64 + kind`, Tier 3), weather and terrain (reserved), `Rejuvenate` (D7/Tier 3), `Resurrect` (D7).
- Any new `DeathCause`; any lot write except through `Goods`; any remote transfer between people (a miracle never moves a lot between holders except emptying a destroyed hut's bins to the ground at zero distance).
- Any Unity effect (U3b draws from D3's events). D6's meaning of shrines and offerings bins.
