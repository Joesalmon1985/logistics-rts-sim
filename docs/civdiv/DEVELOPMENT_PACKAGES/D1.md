# D1: Gods, Mythic and the divine command interface

Package spec for the Civilisation and Divinity run (owner brief 26 Nov 2026 §40). Self-contained: an agent can work from this file plus the documents it links. Paths are relative to `Assets/God/Sim/` unless they start with `Assets/`, `DotNet/` or `docs/`. "Contracts" = [SHARED_ARCHITECTURAL_CONTRACTS.md](../SHARED_ARCHITECTURAL_CONTRACTS.md) (binding); "index" = [DEVELOPMENT_PACKAGE_INDEX.md](../DEVELOPMENT_PACKAGE_INDEX.md) §2 D1.

## 1. Identifier

**D1**, Tier 1, Checkpoint **B** (Divine sandbox). Interim merge **D1a** after about 1 hour unblocks D2, D3 and U2a. Effort about 2.5 agent-hours. Branch `unity/d1`, worktree `wt-lrs-d1`.

## 2. Objective

Persistent gods, one per initial faction (D5.3-D5.5), each with Mythic under the `Standard`, `Unlimited` and `Disabled` modes (D5.26, D5.27); the same rules for human and AI gods; the divine observation view `IDivineView` (layer 8); `GodDirector` seating AI gods; the scripted test god `ScheduleGod` (the lead's default for test gods, index §0); and the configuration commands. D1 owns the `DivinityModule`, `DivinitySystem` and the hook dispatchers that every other D package plugs into.

## 3. User-facing outcome

In a god-only game the player is one god with a name, an identity colour and a Mythic balance that regenerates daily and is spent by divine actions. A god never disappears, even if its faction is eliminated or its people die out. In sandbox the player can switch which god they control, set a god's AI policy and switch Mythic between Standard, Unlimited and Disabled. Rival gods are AI seats (idle by default). (The meter and toolbar are drawn by U2; D1 supplies the state, the view and the commands.)

## 19. Risks

| Risk | Mitigation |
|---|---|
| The `GodCreated`-on-first-tick rule interacts with save/load (emitted twice) | a persisted `Created` flag per god or the "first divinity tick" computed from state; covered by `D1_SaveLoadParity` |
