# D7: Mind archive and resurrection

Package spec for the Civilisation and Divinity run (owner brief 26 Nov 2026 §40). Self-contained. Paths are relative to `Assets/God/Sim/` unless they start with `Assets/`, `DotNet/` or `docs/`. "Contracts" = [SHARED_ARCHITECTURAL_CONTRACTS.md](../SHARED_ARCHITECTURAL_CONTRACTS.md) (binding).

## 1. Identifier

**D7**, Tier 2, Checkpoint **E** (scenario 14 at E or F). Effort about 3 agent-hours. Branch `unity/d7`, worktree `wt-lrs-d7`.

## 2. Objective

A deceased person is restored with the **same identity, record, NpcId and memories**, while property already distributed stays with its present owners (scenario 14; D5.12, D5.13). The mind of the dead is archived at death through F1's `ArchiveMind` site (blocker 3), dormant (never processed per tick), so resurrection after generations is possible when retention allows.

## 3. User-facing outcome

The player opens the memorial of a villager who died of wounds, sees what happened to their estate, and resurrects them (Lesser, Full or Restoration at different costs and starting health). The villager stands up at the grave with an empty carry, remembers their home, kin, friends and habits, walks to where they think home is, and finds their things now belong to their heirs and their partner possibly remarried. The death stays in the record; the life history shows a second life. (The memorial panel is U5's; U3b draws the effect.)

## 6. Allowed scope

- `DivinityHooks.ArchiveMind` body (`DivinityHooks.D7.cs`): with `Divinity.Enabled = 1` and `Divinity.Resurrection.Archive != Off`, store `ArchivedLife { Npc, LifeNo, DiedTick, Cause, Node, AgeTicksAtDeath, AssociationStore Store, KinMind Kin, SocialMind Social, DivineMind Divine, BeliefStore Beliefs (optional by tuning) }` in `DivinityState.Archive`, sorted by NpcId, one current entry per person (`NpcArchived` 881 at Full only). With Divinity off or `Archive = Off`, nothing happens (cognition part keeps `-1` for the dead).
- Retention `Off | All | RecentDays` with `ArchiveMax` and deterministic eviction (oldest `DiedTick`, ties by id). **Dormant**: no system iterates the archive per tick; saved and hashed in `divine`.
- `Resurrect { God, Npc, Variant, Node }` handler (`InterventionKind.Miracle`): validates dead, a person, archived (refuse `bad_target`/`not_a_person`/`target_dead` semantics per contracts; "no memories" → refuse unless a tuning flag allows mindless return, default off); node rule (Standard: death node, near grave/estate bin, a D3 consecrated place of the god, or the god's avatar node; Unlimited: any land node in sight); cooldown 1 day per person; cost Lesser 30 / Full 60 / Restoration 90 Mythic × `(1000 + YearsDeadPermille × years dead)/1000`, capped × 5.
- State change in one tick: the **same `Npc` record and NpcId** (`Alive = true`), mind rebuilt from the archive (store, kin, social, divine, beliefs), traces/episodes/inbox empty; body by variant (RESURRECTION §4.2 table, per mille → micro units); `DiedTick = 0`, `DeathCause = None` on the record (the death stays in events, warehouse and `DeathsByCause`); **`BioAgeOffset += Tick − DiedTick`** (biological age = age at death); an `OldAge` death returns at `MaxAge − OldAgeGrace` (0.25 years) via `BioAgeOffset` with the flag in the event; `Household = 0`, `HomeHut = 0`, `Stage` from biological age; **empty carry**; saved keyed streams continue (no new streams); obligations that fell due while dead are left to the social memory's own rules.
- `NpcResurrected` (880, with `LifeNo`), `NpcRestoredFromArchive` (882); resurrections counted in `DivinityState` for invariant P-C (`living = founders + births + immigrants + resurrections − deaths − emigrants`); a loud `DivineSign` at the node (D3's ring if merged, else D7 emits only the events); the resurrected person keeps `SelfFeature` exposure per the design if cheap.
- Pin **P9** `Archive_Neutral`; `fact_life_spell`.

## 7. Excluded scope

`Rejuvenate` (Tier 3; code 883 reserved), `AskJoinHousehold`, property claims through justice (C9), restoring partnerships, care, employment, household membership or hut rights (never, D5.13), packed archive tiers, digests, moving dead records out of the hot list, any change to `PopulationStats` or `DeathsByCause`, generation-scale natural lineages (blocker 10: test on an archived record from a fixture, not a natural multi-generation run).

Required tests: save with archived minds → load → resurrect = the same result as without the save; save **after** a resurrection → load → continue = uninterrupted hash (`D7_SaveLoadParity`). No `SaveFile.cs` edit.

## 19. Risks

| Risk | Mitigation |
|---|---|
| A system assumes the dead never return (a cache of "dead ids", estate code re-opening, household candidate lists) | T3, T6 and a 10-day run after a resurrection with all invariants on; report the site to its owner |
| Restored mind not byte-equal (references shared with the dead record) | deep copy on archive and restore; byte-equal hash test T1 |
| The design's archive model (moving the dead out) is tempting for performance | forbidden (hash change); T8 shows the dormant archive is already free per tick |
| Save size grows with the archive | `ArchiveMax`, `RecentDays`; measured and reported |
| Keyed RNG streams re-forked on restore | forbidden: the saved streams continue (contracts §4.4) |
