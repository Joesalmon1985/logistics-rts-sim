## 6. Explicitly excluded scope
**D9 rules, binding on every line of this package** (amendment §§1-5, §D9.1, contracts §23):
- **No title, no permission.** The world records holder, location, quantity, condition, occupancy, labour and objective history; never a rightful owner, use right, membership gate or theft. No `.Owner`, `OwnerRelation`, `Permits.`, `StoreAccess`, `RightOn`, `Truth(` reference anywhere under `Unified/` or in a unified branch of a shared file (U-P3 static guard). A founder or contributor is provenance only. No adapter recreates title or access control; a claim is a brain belief, never world state.
- **No high-level verbs.** The only actions are the twelve `Prim` controls through `Motor.Submit`. No new learning `Verb`, `NpcVerb`, `MaxCand` change, goal table, `Build`/`Gather`/`Trade` action or `MoveTo` for an NPC; construction, collection, exchange and conflict are interaction effects reached by `USE`, `TAKE`, `DROP` and `GESTURE`.
- **No scripted behaviour.** No build order, shelter goal, profession, role, reciprocity, retaliation or "best site" selection in the game. A scripted teacher exists only in `DotNet/God.Train` and test fixtures, labelled `ControlOrigin.Teacher` or `Fixture`, and never drives an evaluation population.
- **Physical gates only.** A control may fail only for reach, inputs, capacity, weight, occupancy, passability, a physical barrier, time or a known-design requirement (`NotKnown` is a legality fact of the brain's knowledge, not a permission). A belief, claim, group, household, tribe or legacy owner field never blocks anything (EP-01).
- **One executor, origin-neutral.** Policy, possession, avatar, compulsion, fixtures and the teacher submit the same `PrimitiveControl`; origin is recorded on events and never changes a physical result (QA-01, U-P4).
- **Legacy untouched.** `Unification.Enabled = 0` is byte-identical to the base (U-P1). Legacy Stage 3, M3-M5 and C1-C7 code stays compiled and pinned; unified code never reads legacy ownership or permission paths (audit §8). Emit nothing rather than delete events.
- **Scale (D10).** Nothing is sized by tribe count, board size or population; every such number is configuration (23.1). Perception and witnesses go through `ISpatialIndex`; cost is O(active persons + changed entities) per tick; no all-pairs scan, no per-tick allocation on hot paths, no `Dictionary` iteration or wall clock; integers and keyed `Rng` forks with labels unique per call site.

Specific to UN0: no behaviour (no motor, no world, no catalogue content, no brain, no effects: handlers are other packages'); no events emitted (UN0 lands ranges and empty arrays only); **no save-version bump** and no edit to `SaveFile.CurrentVersion` (lead only); no `MaxCand` change, no `Verb`/`NpcVerb`/`SelfFeature`/`SituationKind`/episode-key rows (R81: the unified brain does not use the legacy candidate path); no deletion of Stage 3 or legacy ownership code; no new runner scenario; no warehouse tables or migrations (UN11a); no tuning numbers beyond the §23.1 table (packages add their own in `UnifiedTuning.UNn.cs`); no behaviour change of any existing test when `Enabled = 0`.
